# Separate Design and Implement Decisions

We want to broadly separate design and implementation precedent so that each step (design and implement) can filter accordingly.  So each decision will be tagged with a new scope field, which can be design or implement.  Sundial query is updated to include a --scope parameter to indicate which scope we are in. DRs missing scope are treated permissively.
